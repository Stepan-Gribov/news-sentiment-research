# Анализ тональности финансовых новостей

Это продолжение исследования после защиты магистерской работы. Ноутбуки защищённой ВКР 2025 года с FinBERT собраны отдельно: [исходники магистерской ВКР](https://github.com/Stepan-Gribov/mutual-funds-news-thesis).

Код дальнейшего исследования связи тональности российских финансовых новостей с показателями рынка Московской биржи и позициями инвестиционных фондов. Пайплайн собирает и очищает новости, сопоставляет их с эмитентами, классифицирует тональность и формирует месячные данные для регрессий.

- [datamining/](datamining/) — сбор ссылок и извлечение текста статей.
- [scripts/31_run_target_llm_sentiment.py](scripts/31_run_target_llm_sentiment.py) — разметка тональности новостей по эмитентам через локальный сервер языковой модели. В проекте также есть пакетная разметка Gemma и сравнение с Qwen.
- [src/dissertation_pipeline/](src/dissertation_pipeline/) — общие модули для новостей, котировок и портфелей фондов.
- [scripts/run_title_name_regressions.py](scripts/run_title_name_regressions.py) — оценка панельных регрессий по размеченным новостям. В проекте также есть расчёты с поправками на рыночные факторы и индекс.
- [config/](config/) и [notebooks/](notebooks/) — спецификации исследования, списки эмитентов и ноутбук с регрессиями.

## Запуск

Создайте и активируйте виртуальное окружение Python в корне репозитория:

```bash
python -m pip install -r requirements.txt
python -m pip install -e .
python scripts/31_run_target_llm_sentiment.py --help
```

Переменная окружения `DISS_SUPP_ROOT` задаёт папку с входными данными. Для разметки нужен подготовленный файл JSONL и запущенный локальный сервер модели. Для полного повторения исследования также понадобятся исходный корпус новостей, веса моделей, котировки и данные по фондам. В портфолио включены исходники, настройки исследования и ноутбук. Таблицы с агрегатами по позициям фондов нужно подготовить локально скриптами `13_build_company_search_names_from_holdings_dataset.py` и `15_build_top500_securities_news_names.py`.
